## Decisions (ADR)

`docs/decisions/` holds ADRs: one per decision with real alternatives and lasting consequences
(structure, tooling, workflow), or a step in a path others must continue.
Bug fixes, config changes and anything that should have been right already go in the commit
and PR description instead. When unsure, it is not an ADR.
